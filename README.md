# 🛡️ SentinelScan

A modular, extensible IoC (Indicator of Compromise) scanning API built with Flask. SentinelScan queries multiple threat intelligence sources in parallel and returns a normalized, aggregated verdict for each indicator submitted.

---

## Features

- **IoC Scanning** — Submit IP addresses for threat intelligence lookups
- **Parallel Execution** — All configured connectors run simultaneously via `ThreadPoolExecutor`
- **Aggregated Verdict** — Highest-severity result across all sources is surfaced as the overall verdict
- **Rate Limiting** — Per-source rate limits via Flask-Limiter to protect API key quotas
- **Swagger UI** — Interactive API documentation auto-generated by flask-restx
- **Blueprint Architecture** — Each IoC type is isolated in its own Flask Blueprint with its own restx namespace
- **Extensible Connectors** — Adding a new threat intel source requires implementing one class and registering it in the registry

## Getting Started

### Prerequisites

- Python 3.11+
- [uv](https://docs.astral.sh/uv/) package manager

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/your-username/sentinelscan.git
cd sentinelscan

# 2. Create virtual environment and install dependencies
uv sync

# 3. Configure environment variables
cp .env.example .env
```

Open `.env` and add your API keys:

```env
FLASK_ENV=development
FLASK_SECRET_KEY=change-me-please

OTX_API_KEY=your_otx_api_key_here
OTX_RATE_LIMIT=10
```

### Running the App

```bash
uv run python run.py
```

The API will be available at `http://localhost:5000`.
Swagger UI is at `http://localhost:5000/api/scan/docs`.

## API Reference

### `POST /api/scan/ip/scan`

Submit an IPv4 address for threat intelligence scanning.

**Request body**
```json
{
  "ip": "8.8.8.8"
}
```

**Response**
```json
{
  "ioc": "8.8.8.8",
  "ioc_type": "ip",
  "overall_verdict": "clean",
  "sources_scanned": 1,
  "results": [
    {
      "source": "OTXv2",
      "ioc": "8.8.8.8",
      "ioc_type": "ip",
      "verdict": "clean",
      "confidence": 0.1,
      "details": {
        "pulse_count": 0,
        "country": "United States",
        "asn": "AS15169 Google LLC",
        "reputation": {}
      },
      "error": null
    }
  ]
}
```

**Verdict values**

| Verdict | Meaning |
|---|---|
| `malicious` | Found in 3+ threat intelligence pulses |
| `suspicious` | Found in 1–2 pulses |
| `clean` | No threat intelligence hits |
| `unknown` | Scan failed or source returned no data |

## Adding a New Connector

1. Create `app/connectors/your_source.py` extending `BaseConnector`:

```python
from app.connectors.base import BaseConnector

class YourSourceConnector(BaseConnector):
    name = "YourSource"

    def scan_ip(self, ip: str) -> dict:
        try:
            # Call your API here
            return {
                "source":     self.name,
                "ioc":        ip,
                "ioc_type":   "ip",
                "verdict":    "clean",
                "confidence": 0.9,
                "details":    {},
                "error":      None,
            }
        except Exception as exc:
            return self._error_result(ip, exc)
```

2. Register it in `app/connectors/registry.py`:

```python
from app.connectors.otxv2 import OTXConnector
from app.connectors.your_source import YourSourceConnector

CONNECTORS = [
    OTXConnector,
    YourSourceConnector,   # ← add here
]
```

The new connector will automatically run in parallel with all existing connectors. No other changes required.
